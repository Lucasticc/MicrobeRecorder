# 菌类实验记录 Android App

专为菌类种植实验设计的 Android 原生应用，支持实验记录、照片拍摄、语音录入、数据导出。全部本地存储，无需联网。

## 功能特性

### 四栏导航
1. **新建记录** — 首页统计 + 快速新建 + 最近记录
2. **导出** — Excel/Word 导出，按种植日期+处理组筛选
3. **历史记录** — 搜索 + 批量删除
4. **实验管理** — 处理组管理（按种植日期分组）

### 新建实验记录
- **记录日期**: 自动定位当天日期，可手动修改
- **种植日期**: 日期选择器
- **处理组**: 下拉选择（从处理组管理加载）
- **上次实验参照**: 自动显示同处理组上次记录及照片缩略图
- **实验照片**: 拍照/相册多选，最多 5 张，自动归档
- **观察记录**: 多行文本 + 语音输入
- **备注/调整**: 选填
- **录音**: 可选

### 照片管理
- 拍照 + 从相册多选
- 自动归档到: `images/种植日期_处理组/`
- 全屏预览，左右滑动切换
- 编辑模式下可删除照片

### 数据导出
- **Excel (.xlsx)**: 种植日期 | 记录日期 | 处理组 | 观察记录 | 照片1~5 | 备注
- **Word (.doc)**: HTML 格式，图片内嵌
- 支持按种植日期和处理组筛选
- **处理组配置**: Excel格式导出/导入，方便备份和迁移

### 语音识别
自动适配国产手机: 三星(Bixby) / 魅族(Aicy) / 小米(小爱) / 华为(小艺)，通用兜底

### 历史记录
- 搜索 + 批量选择 + 批量删除
- 点击查看详情

## 技术栈
- Kotlin + Android Studio
- Room (SQLite) 数据库
- Apache POI (Excel 导出)
- Glide (图片加载)
- CameraX (相机)
- Material Design 3

## 数据库结构

### microbe_records
| 字段 | 说明 |
|------|------|
| plantingDate | 种植日期 (yyyy-MM-dd) |
| treatmentGroup | 处理组名称 |
| observationResult | 观察记录 |
| notes | 备注/调整 |
| photoPaths | 照片路径（逗号分隔，最多5张） |
| audioPath | 录音路径 |
| createdAt | 创建时间 |

### treatment_groups
| 字段 | 说明 |
|------|------|
| name | 处理组名称 |
| plantingDate | 所属种植日期 |
| description | 描述（可选） |
